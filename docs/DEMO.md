# 演示 Demo 录制指南

这是一个「天气 + 衣橱 → 三套搭配」的单用户 Web 应用，本文件是给要自己录一遍演示的人看的分镜表。
建议成片 2–3 分钟，实际以内容完整为准，不追求时长。

## 录制前准备

- **清掉开发期测试指标**（可选但强烈建议）：`DELETE FROM llm_metrics;`
  这些是开发期调试产生的噪音，不清的话指标面板的降级率会很难看，而「可观测」是卖点之一。
- **准备数据**：`python scripts/seed_30.py`（需要后端已启动），或确保衣橱里至少有 20 件。
- **窗口设置**：浏览器 1280×800、缩放 100%、关掉其他标签页，避免拍到无关内容。
- **录制工具**：Windows 用 `Win+G`（Xbox Game Bar）或 OBS；输出 1080p mp4。
- **隐私检查**：设置弹层里填 key 时要遮住输入内容，全程不要录到完整 key。

## 分镜表

| 段 | 目标 | 操作 | 口播 | 时长 |
|---|---|---|---|---|
| **S1** | 说清这是什么 | 停在「搭配」页首屏 | 「一个记录自己衣服、按当天天气和场合出三套搭配的应用，单用户，不需要注册。」 | 约 15s |
| **S2** | 证明录入够快 | 连选 3 张图，只用键盘：`1` → `W` → `Enter`，重复三次 | 「一件衣服三次点击：品类、厚薄、保存。熟练之后不用碰鼠标。」 | 约 25s |
| **S3** | 衣柜与冷启动现状 | 切「衣柜」，点「上衣」筛选，再点「信息不全」 | 「九宫格按品类筛；信息不全是冷启动时的真实状态，标出来提醒自己补。」 | 约 20s |
| **S4** | 规则推荐可用 | 切「搭配」，指天气条与三张卡片 | 「天气取今天的体感温度，温度用 CMA 模型、降水和 UV 用另一个模型；三套搭配是规则算的，每套有理由。」 | 约 25s |
| **S5** | AI 精选与防幻觉 | 设置里填 key（遮住）→ 开「AI 精选」→ 等加载 → 看徽标 → 同一场合再点一次 | 「模型只从规则挑出的候选里选 id，后端校验越界、件数、重复和品类，不合法就让模型重出一次。」 | 约 30s |
| **S6** | 保存搭配 | 点第一张卡片的「就穿这套」 | 「点一下就落库成今天穿这套，`wear_log` 视图里能直接查到这几件。」 | 约 15s |
| **S7** | 可观测 | 新标签打开 `/api/metrics?days=30` | 「调用量、成功率、降级原因分布、token 消耗都在这；延迟分成请求级和模型级两组分位。」 | 约 20s |
| **S8** | 兜底与边界 | 清除 key 后再开 AI 开关 | 「没有 key、超时、限流都会退回规则推荐，页面永远有结果，不会白屏。」 | 约 10s |

## 口播要点

四个亮点各分配一处，每处一句话：

- **多模型适配 + 无 key 降级**（S8、S4）：模型层是 OpenAI 兼容协议，换供应商只改两个环境变量；没有 key 就走规则，接口永远 200。
- **候选集约束 + 校验修复防幻觉**（S5）：模型只输出 id，四条硬校验拦住越界和缺件，失败回灌错误重出一次，再失败降级。
- **成本与延迟可观测**（S7）：每次请求落一行指标，模型级延迟和请求级延迟分开统计。
- **零 key 对外可跑**（S8）：服务端不配 key 也能完整运行，访客自带 key 才体验 AI；限流按 IP 每分钟 10 次。
